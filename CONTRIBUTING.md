# Contributing

Start new work from `unstable` and target pull requests to `unstable`.

`main` accepts reviewed integration through pull requests with a passing `verify` check and one approval. `stable` is the locked baseline and advances only for an explicitly selected release. Force pushes and branch deletion are disabled on these branches.

Keep host credentials, personal account defaults, database exports and unlicensed assets out of source. Follow the security boundaries and checks documented in the README and source-review notes. Account-linking UI and popup lifecycle are not third-party login assertions.
